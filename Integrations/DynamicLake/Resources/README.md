# Gaze for DynamicLake

Shows Gaze, the Mac face-unlock app, in DynamicLake's island: when it's looking for your face, the movement it asks for, and when it unlocks. App Lock shows too.

## Setup

1. Install Gaze from https://gazeunlock.com.
2. In Gaze, open Settings, General, and turn on Share status with other apps.

Without that setting, or while Gaze isn't running, this plugin shows nothing.

## Settings

- Show Movement Prompts: show Nod, Blink and the other movements.
- Show App Lock: show when App Lock covers an app.

## Privacy

The plugin only listens to Gaze's on-device status feed. It uses no network and stores nothing.
