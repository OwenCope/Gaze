# Gaze visitor journey and content review

Reviewed 16 September 2026 by Walter 4. Source: `/Users/owencope/Developer/gaze-site`.

This is a read-only review of page copy, component data, links and conditional rendering. It does not establish the deployed release inventory, active sign-in providers, current access settings, actual app compatibility, screenshot appearance or browser behavior. No environment values, release data, authentication flows or builds were accessed. The root reviewer is handling live and visual evidence.

## What is already clear

The homepage explains the product immediately: camera-based face recognition at the Mac lock screen (`src/app/page.tsx:29`, `:34`). Development status is explicit (`:46`, `:82`). The privacy section says that recognition is local and photographs may fool it (`:69`). The Security page distinguishes encrypted recognition measurements, saved login passwords and optional portraits, and explains that recognition authorizes password submission rather than supplying an encryption key (`src/app/security/page.tsx:8`, `:43`). Keep these distinctions and the regular-camera limitations.

The unresolved visitor questions are mainly practical. Compatibility is tucked inside a notch FAQ; access is divided among Discord, Releases and website sign-in; the open-source claim has no direct repository link in the reviewed navigation; support is easy to find on Home but disappears from the footer of the three explanatory pages. The Features and How it works routes repeat much of Home's setup imagery instead of consistently answering the next question.

## Scope boundaries

- The existing security limitations, restart requirement, local processing claims and preview labels should remain. This review does not justify claims of Face ID equivalence, guaranteed spoof resistance, measured unlock speed or measured battery impact.
- Sign-in provider availability and the Releases gate are conditional in source. No claim is made that a provider is missing, a sign-in is broken, a particular release exists, or a current visitor receives a particular redirect.
- Compatibility must be checked against the actual downloadable build before publishing OS/chip values. The broad MacBook/iMac claim in the FAQ has not been independently validated here.
- No website files were changed. This report is the only saved artifact.
