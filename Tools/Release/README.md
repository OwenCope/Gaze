# Release work

- [DMG packaging](DMG/README.md): artwork, drag-to-Applications layout and packaging command.
- [Readiness](READINESS.md): the release requirements and remaining acceptance work.
- [Model and asset clearance](ModelClearance/README.md): evidence required before distribution.
- `preflight.sh`: inspect prerequisites without building or publishing.
- `verify.sh`: check a signed, notarized release app.
- [Latest app build checkpoint](UXTightening20260917/BUILD-CHECKPOINT.json).
- [App and website UX review](UXReview20260917/RESULT.md).

The other folders retain previous investigations, patch proposals, fixtures and
their evidence. Website copies here are reference or staged files, not the live
`gaze-site` checkout. No report or patch is proof that it has been deployed.

Packaged installers are in `build/installers/`. Older generated app backups, logs,
screenshots and review outputs are in `build/archive/`, separate from these sources.
