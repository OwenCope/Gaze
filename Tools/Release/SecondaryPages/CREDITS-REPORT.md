# Credits page

The Credits page now uses a compact, static list with 72px portraits on small screens and 96px portraits from 640px upward. Each credit retains its name, description, contribution, portrait selection, contact links, primary destination, side-app destination, and rights line.

The page introduction now reads “Made with a little help.” and “The people, projects, and ideas behind Gaze.” Server-side contribution fetching and the existing footer attribution remain in place. The redundant back link was removed because the persistent top navigation already provides site navigation.

No build or browser verification was run in this task. Combined verification belongs to the root task.

## Card-grid revision

Following visual review, the flat rows were replaced with two compact card grids: projects use two columns from 768px, while people use two columns from 640px. Project cards now link their names directly, keep 80px local icons and full rights lines, and people cards retain 56px portraits, profile/contact links, and the side-app link. All cards use the shared surface, hairline, and shadow tokens without scroll or hover motion.
